# Problem-6-Beautifying-Meadville
This project is focused on developing algorithms in the hopes of beautifying Meadville. We will do this by finding an algorithm that will efficiently determine where we can plant trees along the streets of Meadville. We will first determine the baseline approach to this problem and then find a more effcient algorithm to minimize the number of steps required for this algorithm to run.
